# Project Structure Documentation

## Directory Organization

### Root Level Files

- **README.md**: Main project documentation
- **QUICKSTART.md**: Quick start guide for new users
- **CONTRIBUTING.md**: Contribution guidelines
- **LICENSE**: MIT License
- **requirements.txt**: Python package dependencies
- **.gitignore**: Git ignore rules
- **PROJECT_SUMMARY.md**: Executive summary

### Source Code (`src/`)

#### `src/dashboard_app.py`
Main Dash application file containing:
- Data loading and validation
- UI layout and components
- Callback functions for interactivity
- Chart generation functions
- Server configuration

#### `src/data_cleaning/`
Data cleaning pipeline modules:
- `__init__.py`: Package initialization
- `data_clean_Step0_preprocessing.py`: Text normalization
- `data_clean_Step1.py`: QuestionID merging
- `data_clean_Step2.py`: ResponseID merging
- `data_clean_Step3.py`: BreakoutID merging
- `data_clean_Step4.py`: Numeric cleaning
- `data_clean_Step5.py`: Data aggregation
- `data_clean_Step6.py`: Quality enhancement

### Data Directory (`data/`)

#### `data/raw/`
- Placeholder for raw dataset.csv (gitignored)
- Users must download and place dataset here

#### `data/processed/`
- `cleaned_data_final_enhanced.parquet`: Final processed data
- Used by dashboard application

### Documentation (`docs/`)

- `ARCHITECTURE.md`: System architecture details
- `DATA_PIPELINE.md`: Data processing pipeline documentation
- `DEPLOYMENT.md`: Deployment instructions

### Scripts (`scripts/`)

- `run_pipeline.py`: Execute full data cleaning pipeline

## File Dependencies

```
dashboard_app.py
    ↓ depends on
cleaned_data_final_enhanced.parquet
    ↓ generated by
run_pipeline.py
    ↓ executes
data_clean_Step0-6.py
    ↓ processes
dataset.csv (in data/raw/)
```

## Code Organization Principles

1. **Separation of Concerns**: Data cleaning separate from visualization
2. **Modularity**: Each step is a separate module
3. **Reusability**: Functions can be imported and reused
4. **Maintainability**: Clear structure and documentation
